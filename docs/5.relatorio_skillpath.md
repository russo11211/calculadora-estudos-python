### 1. Objetivo do Projeto
Desenvolver uma aplicação funcional em modo terminal utilizando Python 3 puro, focada em resolver problemas práticos de planejamento e gestão de rotina de estudos através das quatro operações matemáticas fundamentais (adição, subtração, multiplicação e divisão), com ênfase em código modular, legível e seguro contra falhas de entrada.

---

### 2. Descrição da Aplicação Python
A aplicação "Calculadora de Organização de Estudos" é uma ferramenta interativa via linha de comando que oferece um menu cíclico de opções. Ela calcula horas acumuladas, saldo restante para bater metas, estimativas de tempo com base em sessões e divisão de carga horária por dias úteis, prevenindo divisões por zero e caracteres inválidos.

---

### 3. Arquivos Gerados
- `calculadora_estudos.py`: Arquivo principal contendo a lógica das funções matemáticas, sanitização de inputs, menu dinâmico e fluxo de controle.

---

### 4. Funcionalidades Implementadas
- [x] Menu interativo com loop contínuo (`while True`) e encerramento controlado.
- [x] **Adição:** Totalização de blocos de estudo diários.
- [x] **Subtração:** Verificação de saldo de meta com feedback condicional (meta batida, superada ou pendente).
- [x] **Multiplicação:** Cálculo de projeção de carga horária por sessões de estudo.
- [x] **Divisão:** Distribuição proporcional de estudo em dias úteis com prevenção de `ZeroDivisionError`.
- [x] Validador de dados numéricos (`ler_float`) com tolerância para vírgulas decimais (`3,5` -> `3.5`) e tratamento de exceção (`ValueError`).
- [x] Formatação numérica profissional em duas casas decimais (`:.2f`).

---

### 5. Conceitos de Programação Utilizados
- **Variáveis e Tipagem de Dados:** Manipulação de tipos primitivos (`str`, `float`, `int`, `None`).
- **Funções Modulares:** Funções com responsabilidade única (`Single Responsibility Principle`), parâmetros nomeados e retorno explícito (`return`).
- **Operadores Matemáticos:** Aplicação de `+`, `-`, `*`, `/`.
- **Controle de Fluxo e Condicionais:** Estruturas `if`, `elif` e `else` para roteamento de opções e validação de regras de negócio.
- **Tratamento de Exceções:** Uso de blocos `try-except` para capturar `ValueError` em entradas de texto onde se esperavam números.
- **Laços de Repetição:** Utilização de `while True` com saídas condicionadas por `break`.
