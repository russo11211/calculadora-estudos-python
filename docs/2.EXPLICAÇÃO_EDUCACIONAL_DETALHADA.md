EXPLICAÇÃO EDUCACIONAL DETALHADA
1. Quais são os componentes principais?
A aplicação é dividida em três camadas estruturais:
Funções de cálculo: somar_horas, subtrair_meta, multiplicar_sessoes, dividir_horas_por_dias. Cada uma foca estritamente em realizar um cálculo e devolver o resultado.
Função de interface e validação: ler_float (garante que apenas números sejam aceitos) e exibir_menu (apresentação visual).
Função controladora de fluxo (main): gerencia o laço de repetição (while True), captura a escolha do usuário e chama as funções apropriadas.
2. Como o programa recebe os números?
Por meio da função ler_float(), que encapsula o comando input():
code
Python
entrada = input(mensagem).strip().replace(",", ".")
O método .strip() elimina espaços em branco acidentais antes ou depois da digitação. O .replace(",", ".") converte o formato decimal brasileiro com vírgula (ex.: 2,5) para o formato padrão do Python com ponto (2.5). Em seguida, float(entrada) tenta converter o texto recebido para número decimal. Se o usuário digitar algo não numérico (como "abc"), a exceção ValueError é capturada e uma mensagem de erro é exibida sem interromper a execução do programa.
3. Como identifica a operação escolhida?
O menu captura uma string digitada pelo usuário e a avalia utilizando estruturas de decisão:
code
Python
opcao = input("Escolha uma opção (0 a 4): ").strip()
if opcao == "0":
    ...
elif opcao == "1":
    ...
A opção é comparada diretamente com textos ("0", "1", "2", etc.). Isso evita falhas de conversão de tipos caso o usuário digite uma letra ou símbolo.
4. Quais variáveis são utilizadas?
opcao (tipo str): armazena o comando digitado no menu.
h1, h2, meta, feitas, sessoes, duracao, horas, dias (tipo float): armazenam os parâmetros numéricos recebidos do usuário.
resultado, restantes, total, media (tipo float ou None): armazenam o retorno calculado por cada função específica.
5. Como os valores são armazenados?
Os valores são armazenados na memória RAM do computador durante o ciclo de vida do programa. O escopo da maioria dessas variáveis é local à função main() ou às funções matemáticas. Quando uma iteração do laço recomeça, variáveis temporárias recebem novos valores sobrescrevendo os anteriores.
6. Como funcionam as estruturas condicionais?
O programa utiliza if, elif e else para guiar o fluxo:
Seleção de rota: Apenas um bloco do menu é executado por rodada. Se opcao == "1" for verdadeiro, todas as verificações seguintes (elif opcao == "2", etc.) são ignoradas.
Tratamento de exceções lógicas (Divisão por zero):
code
Python
if dias_disponiveis == 0:
    return None
Se a condição for verdadeira, a função interrompe a operação antes de tentar a divisão, evitando o erro nativo ZeroDivisionError.
Tratamento de opção inválida: Se nenhuma condição for atendida, o bloco final else: é acionado para avisar o usuário.
7. Como os cálculos são realizados?
Os cálculos ocorrem em linhas dedicadas através dos operadores nativos do Python (+, -, *, /):
horas_a + horas_b
meta_total - horas_feitas
total_sessoes * horas_por_sessao
horas_totais / dias_disponiveis
8. Como o resultado é apresentado?
Através do comando print() formatado com f-strings:
code
Python
print(f">> Total acumulado: {resultado:.2f} horas de estudo.")
A diretiva :.2f limita a exibição a duas casas decimais com arredondamento automático, ideal para expressar tempo e frações de hora de maneira limpa.
9. Como as funções são chamadas?
As funções são invocadas pelo nome passando os argumentos esperados entre parênteses:
code
Python
resultado = somar_horas(h1, h2)
O valor retornado pela palavra-chave return é recebido e atribuído à variável resultado, ficando disponível para apresentação.
