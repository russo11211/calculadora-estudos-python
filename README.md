# 📚 Desafio 1 Alura — Calculadora de Estudos em Python

Projeto prático desenvolvido durante o curso **Desenvolvimento com IA** da Alura.

A aplicação é um utilitário em linha de comando (CLI) construído em Python 3 puro que aplica as quatro operações aritméticas básicas para apoiar o planejamento e organização de estudos.

## 🚀 Funcionalidades
- **Adição:** Soma de blocos de horas de estudo.
- **Subtração:** Cálculo de horas restantes para atingir metas de estudo.
- **Multiplicação:** Estimativa de tempo total por número e duração de sessões.
- **Divisão:** Distribuição equilibrada de carga horária entre dias disponíveis.
- **Validação de Dados:** Prevenção contra divisões por zero e sanitização de entradas inválidas ou formatos com vírgula.
